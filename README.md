# LSCD — Registration Page (preview)

Temporary public preview of the registration page for the
Laredo School of Contemporary Dance.

**Live:** https://javmartz04-ship-it.github.io/lscd-registration/

Source of truth is `builds/lscd-registration/index.html` in the
"Design - Funnels - Website" folder. This repo is a deploy target only.

Note: the form runs in safe-preview mode (`CONFIG.endpoint` is empty), so
submissions are stored in the visitor's browser and are not sent anywhere.
This copy is set to `noindex,nofollow` for that reason.
